Balancing Equations

An equation is a balance scale. The = sign means both sides weigh the same. You can do anything you like, as long as you do it to both sides so the scale stays level.

For grown-ups: Why these are tricky
  • Doing something to only one side. The scale picture makes this mistake visible: one side drops.
  • Not knowing which move comes first. Undo things in reverse order: the last thing done to x comes off first.
  • x on both sides (multi_alg), parentheses and fractions (hard_alg). Each needs one extra move, which steps 3 and 4 show.
Step 1

What number makes it balance?

Every orange x tile weighs the same secret amount. Slide to try different weights. The scale tips toward the heavier side. When it's level, you've found x.

Step 2

Undo in reverse order

Read the equation as a machine: x goes in, things happen to it, and the answer comes out. To find x, run the machine backwards, doing the opposite of each step.

Step 3 · multi_alg

x on both sides

First get all the x tiles on one side: take the smaller pile of x's off both sides. Then it's an equation like step 2. Red dashed coins are minus numbers: adding the same amount cancels them.
